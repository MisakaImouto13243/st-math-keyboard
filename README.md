# 数学公式键盘

SillyTavern 界面扩展。用悬浮球打开一块虚拟键盘，点按钮拼出 LaTeX 公式，
面板里自带 KaTeX 预览，再把公式以 `latex` 代码块插进聊天输入框。

## 它是怎么工作的

```
悬浮球（可拖、可吸边、位置会记住）
   ↓ 点击
键盘面板
   ├─ 预览区：本地 KaTeX 渲染，看到的就是公式最终长相
   ├─ 草稿框：可直接手打，也可以点下面的按钮拼
   ├─ 12 类符号键：常用模板 / 希腊字母 / 运算符 / 关系符 / 箭头 /
   │   大型算子 / 函数 / 上下标 / 矩阵方程组 / 装饰 / 定界符 / 文字间距
   └─ 插入聊天框 / 复制 / 清空
   ↓ “插入聊天框”
酒馆输入框收到：
```latex
\frac{a}{b}
```
   ↓ 发送后
聊天消息里的公式由官方 LaTeX 扩展渲染成数学样式
```

## 安装

### 前置条件

- SillyTavern **1.17.0 或更新**（本扩展用了 1.17 引入的生命周期钩子；开发时在 1.18.0 上验证）。
- 想看到聊天里的公式，需要**开启官方 LaTeX 扩展**：扩展面板里找到 `LaTeX` 并启用。
  注意它只认带 `latex` / `asciimath` 语言标记的代码块，不认 `$...$` 行内写法。
  本扩展插入的正是它认的格式。

### 手动安装（用户作用域）

1. 把整个 `st-math-keyboard` 文件夹复制到：

   ```
   <你的酒馆目录>/data/<用户名>/extensions/
   ```

   例：`E:\SillyTavern\SillyTavern-1.18.0\data\default-user\extensions\st-math-keyboard\`

2. 在浏览器里刷新酒馆页面。
3. 打开扩展面板，找到「数学公式键盘」并启用。
4. 加载完成后，界面右下角会出现悬浮球。

扩展文件夹名就是它的身份标识（设置命名空间），改名会让旧设置读不出来。

### 从 GitHub 自动安装（推荐，便于以后更新）

前提：本仓库已经推到 GitHub，且**仓库名就是 `st-math-keyboard`**。

1. 打开酒馆的「扩展程序」面板（管理扩展程序）。
2. 在「安装扩展程序」里粘贴仓库地址，例如：

   ```
   https://github.com/<你的用户名>/st-math-keyboard
   ```

3. 如果代码在别的分支上，再填上分支名；默认分支留空即可。
4. 点安装。酒馆会把仓库克隆到 `data/<用户名>/extensions/st-math-keyboard`。
5. 刷新酒馆页面，启用「数学公式键盘」，并开启官方 `LaTeX` 扩展。

关于更新的两点注意：

- 酒馆是**浅克隆（depth 1）**，且安装时若目标文件夹已存在会直接报 409 冲突；
  重装前先删掉旧文件夹，或用面板里的「更新」按钮拉取新提交。
- `manifest.json` 的 `auto_update` 为 `false` 时，更新由你手动点；改成 `true` 则随酒馆自身的更新流程一起拉取。

仓库根目录必须直接就是本扩展的根目录（根下能看到 `manifest.json`），
不能把扩展再套一层文件夹 —— 酒馆安装后会立刻读取根目录的 `manifest.json`，
读不到就回滚删除。

## 使用

- **打开键盘**：点悬浮球。再点一次、按 `Esc`、或点面板右上角 ✕ 收起。
- **移动悬浮球**：按住拖动，松手后会吸附到最近的一侧，位置自动记住。
- **拼公式**：点符号键，片段会插到草稿框的光标处；带空花括号的模板会把光标停在待填位置。
- **预览**：预览区实时渲染草稿内容；公式写错时会用红字提示。
- **插入聊天框**：写入一个 `latex` 代码块，光标停在代码块之后。
- **复制**：只复制 LaTeX 原文，方便贴到别处。

## 设置面板

扩展面板里的「数学公式键盘」区块：

- **显示悬浮球**：关掉后球会隐藏。这是悬浮球被拖到不好点的位置时的兜底开关。
- **插入聊天框后清空草稿**：默认开。
- **重置悬浮球位置**：回到右侧默认位置。键盘用户也能靠它恢复入口。

## 依赖与体积

- 自带 **KaTeX 0.16.11**（`vendor/katex/`，MIT 许可，随包附 LICENSE），用于面板内预览。
  运行时不联网，公式不会离开本机。
- 除此之外无第三方依赖，不读取聊天内容、不修改提示词、不注册命令。

## 已知边界

- 插入的是 `latex` 代码块，**不是** `$...$` 行内公式；行内渲染需要你自己改写法。
- 不检测官方 LaTeX 扩展是否启用。若它没开，聊天里会看到代码块原文而不是渲染后的公式。
- 聊天里能不能渲染，由官方 LaTeX 扩展负责，本扩展管不到。
- 深色/浅色外观跟随酒馆主题变量；若主题缺变量则使用内置的深色兜底值。
