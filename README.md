# 数学公式键盘

SillyTavern 界面扩展。用悬浮球打开一块虚拟键盘，点按钮拼出 LaTeX 公式，
面板里自带 KaTeX 预览，再把公式以 `latex` 代码块插进聊天输入框。

## 它是怎么工作的

```
悬浮球（可拖、可吸边、位置会记住）
   ↓ 点击
键盘面板
   ├─ 预览区：本地 KaTeX 渲染，看到的就是公式最终长相
   ├─ 草稿框：可直接手打，也可以点下面的按钮拼
   ├─ 12 类符号键：常用模板 / 希腊字母 / 运算符 / 关系符 / 箭头 /
   │   大型算子 / 函数 / 上下标 / 矩阵方程组 / 装饰 / 定界符 / 文字间距
   └─ 插入聊天框 / 复制 / 清空
   ↓ “插入聊天框”
酒馆输入框收到：
```latex
\frac{a}{b}
```
   ↓ 发送后
聊天消息里的公式由官方 LaTeX 扩展渲染成数学样式
```

## 安装

### 前置条件

- SillyTavern **1.17.0 或更新**（本扩展用了 1.17 引入的生命周期钩子；开发时在 1.18.0 上验证）。
- 想看到聊天里的公式，需要**开启官方 LaTeX 扩展**：扩展面板里找到 `LaTeX` 并启用。
  注意它只认带 `latex` / `asciimath` 语言标记的代码块，不认 `$...$` 行内写法。
  本扩展插入的正是它认的格式。


## 使用

- **打开键盘**：点悬浮球。再点一次、按 `Esc`、或点面板右上角 ✕ 收起。
- **移动悬浮球**：按住拖动，松手后会吸附到最近的一侧，位置自动记住。
- **拼公式**：点符号键，片段会插到草稿框的光标处；带空花括号的模板会把光标停在待填位置。
- **预览**：预览区实时渲染草稿内容；公式写错时会用红字提示。
- **插入聊天框**：写入一个 `latex` 代码块，光标停在代码块之后。
- **复制**：只复制 LaTeX 原文，方便贴到别处。

## 设置面板

扩展面板里的「数学公式键盘」区块：

- **显示悬浮球**：关掉后球会隐藏。这是悬浮球被拖到不好点的位置时的兜底开关。
- **插入聊天框后清空草稿**：默认开。
- **重置悬浮球位置**：回到右侧默认位置。键盘用户也能靠它恢复入口。

## 依赖与体积

- 自带 **KaTeX 0.16.11**（`vendor/katex/`，MIT 许可，随包附 LICENSE），用于面板内预览。
  运行时不联网，公式不会离开本机。
- 除此之外无第三方依赖，不读取聊天内容、不修改提示词、不注册命令。

## 已知边界

- 插入的是 `latex` 代码块，**不是** `$...$` 行内公式；行内渲染需要你自己改写法。
- 不检测官方 LaTeX 扩展是否启用。若它没开，聊天里会看到代码块原文而不是渲染后的公式。
- 聊天里能不能渲染，由官方 LaTeX 扩展负责，本扩展管不到。
- 深色/浅色外观跟随酒馆主题变量；若主题缺变量则使用内置的深色兜底值。
